# WebClass 講義資料ダウンローダー（金沢大学）

金沢大学の WebClass から、履修中の科目の「資料」にある PDF をまとめてダウンロードし、
iCloud Drive の「講義資料」フォルダに科目ごとに保存するツールです。
保存した PDF は、あとで Goodnotes に読み込めます。

## このツールがすること・しないこと

**すること**

1. 実行すると、ブラウザの画面が開きます
2. そのブラウザで、**自分で** 金沢大学IDでログインします（多要素認証もブラウザで行います）
3. 今の学期（例：2026年度 Q3）の科目を 1 つずつ見て回り、「資料」を探します
4. 見つかった資料の一覧（科目名・資料名）をターミナルに表示します
5. `y` と答えたときだけダウンロードし、科目ごとのフォルダに保存します
   保存先：`iCloud Drive/講義資料/<科目名>/`
6. 一度ダウンロードした資料は記録しておき、次回からは飛ばします（新しい資料だけ落とします）

**しないこと**

- パスワードの保存（ログインは毎回ブラウザで自分で行うか、前回のログイン状態（クッキー）を使います）
- 自動での定期実行（自分で実行したときだけ動きます）
- 同時に複数のアクセス（1 件ずつ、2 秒以上の間隔をあけて順番に処理します）
- 課題の提出・アンケートの回答・テストの受験など、資料の閲覧とダウンロード以外の操作
  （カテゴリが「資料」の教材しか開きません）

## 準備（最初に 1 回だけ）

### 1. ターミナルを開く

Finder →「アプリケーション」→「ユーティリティ」→「ターミナル」を開きます。
（または `⌘ + スペース` で「ターミナル」と入力して Enter）

### 2. Python が入っているか確認する

ターミナルに次のように入力して Enter を押します。

```bash
python3 --version
```

- `Python 3.9.6` のように表示されれば OK です（3.9 以上なら大丈夫）。
- 「コマンドライン・デベロッパツールをインストールしますか？」という画面が出たら、
  「インストール」を押して、終わったらもう一度上のコマンドを実行してください。

### 3. このツールをダウンロードする

GitHub のこのリポジトリのページで、緑色の「Code」ボタン →「Download ZIP」を押します。
ダウンロードした ZIP をダブルクリックで展開し、できたフォルダを
分かりやすい場所（例：「書類」フォルダ）に移動しておきます。

ここでは例として、フォルダ名を `webclass-downloader` にして「書類」に置いたとします。

### 4. 準備用のスクリプトを実行する

ターミナルで、次の 2 行を 1 行ずつ入力して Enter を押します。

```bash
cd ~/Documents/webclass-downloader
bash setup.sh
```

> 💡 `cd` のあとにスペースを入れて、Finder からフォルダをターミナルにドラッグ＆ドロップすると、
> フォルダの場所を自動で入力できます。

数分かかります。最後に「準備が終わりました」と表示されれば完了です。
（ツール専用のブラウザ Chromium がダウンロードされます。普段使っている Chrome や Safari には影響しません）

## 使い方

### まずは 1 科目だけで試す

```bash
cd ~/Documents/webclass-downloader
./run.sh --course 感染症学
```

1. ブラウザの画面が開き、アカンサスポータルが表示されます。
2. その画面で金沢大学IDでログインし（多要素認証も）、ポータルの「時間割」などから WebClass を開きます。
   > ⚠️ 「メンテナンス用のログイン画面です」と書かれた WebClass の画面には、パスワードを入力しないでください。
   > そこは管理者用の入口なので、正しいIDとパスワードでもログインできません。
3. WebClass の画面が表示されたら、**ターミナルに戻って Enter キー** を押します。
4. ツールが科目を見て回り、見つかった資料の一覧を表示します。
5. 「ダウンロードしますか？ (y/n):」と聞かれたら、`y` を入力して Enter を押します。
   （やめるときは `n`）
6. 終わるとブラウザは自動で閉じます。

保存された PDF は Finder の「iCloud Drive」→「講義資料」→「感染症学」にあります。

> ⚠️ ツールが動いている間は、開いたブラウザの画面を操作しないでください。
> また、同じ時間に普段のブラウザで WebClass を操作するのも避けてください
> （WebClass は「複数の画面で同時に操作しないでください」となっているため）。

### 今の学期の全科目を対象にする

うまくいったら、`--course` を付けずに実行します。

```bash
./run.sh
```

今日の日付から学期を推測して（例：9〜11月なら Q3）、その学期の科目をすべて見て回ります。
科目名の「(Q3)」の部分で判別しています（「(Q3Q4)」のような通しの科目も含みます）。

### デスクトップのアイコンから実行する（ダブルクリックで起動）

ターミナルに次を貼り付けて Enter を押すと（最初に 1 回だけ）、デスクトップにアイコンができます。
ダブルクリックすると、科目の一覧が番号付きで表示され、ダウンロードする科目を選べます。

```bash
cat > ~/Desktop/WebClass資料ダウンロード.command <<'EOF2'
#!/bin/bash
cd ~/Documents/webclass-downloader && ./run.sh --choose --goodnotes --save-dir "$HOME/Documents/勉強/3年"
EOF2
chmod +x ~/Desktop/WebClass資料ダウンロード.command
```

### よく使うオプション

| 書き方 | 意味 |
| --- | --- |
| `--goodnotes` | ダウンロードした PDF を、科目ごとに Goodnotes に読み込む（Goodnotes で科目のフォルダを開いてから「読み込む」を押す） |
| `--choose` | 科目の一覧を表示して、番号で対象の科目を選ぶ（例：`1 3`） |
| `--course 感染症学` | 科目名にこの文字を含む科目だけを対象にする（学期に関係なく） |
| `--term Q4` | 対象のクォーターを指定する（推測が合わないとき） |
| `--term all` | 学期に関係なく、今年度のすべての科目を対象にする |
| `--year 2026` | 対象の年度を指定する |
| `--interval 3` | アクセスの間隔を 3 秒にする（標準は 2 秒、1 秒未満にはできません） |
| `--include-non-pdf` | PDF 以外のファイル（PowerPoint など）も保存する |
| `--save-dir ~/Desktop/test` | 保存先を変える（試しに使うとき） |
| `--debug` | うまくいかないときの調査用に、資料の画面を保存する |

例：`./run.sh --term Q4 --interval 3`

`./run.sh --help` で一覧を見られます。

## 保存のルール

- 保存先：`~/Library/Mobile Documents/com~apple~CloudDocs/講義資料/<科目名>/`
  （Finder では「iCloud Drive」→「講義資料」）
- 科目名のフォルダは「感染症学(Q3)(41165) (2026-通年-集中)」→「感染症学」のように、
  後ろのカッコ部分を取った名前になります。
- ファイル名
  - 添付ファイル型の資料：先生がアップロードした元のファイル名
  - 埋め込み型の資料：教材名（例：「第2回 スライド.pdf」）。節が複数あるときは「_2」「_3」…が付きます
  - 先頭などの「★」は取り除きます
- 同じ名前のファイルがすでにあり、中身が違う場合は「(2)」を付けて別に保存します（上書きはしません）。

## ダウンロード済みの記録について

- ダウンロードした資料は `~/.webclass-downloader/history.json` に記録され、次回からは飛ばします。
- PDF を消しても、記録が残っている限り再ダウンロードはされません。
  **もう一度全部ダウンロードし直したいとき** は、ターミナルで次を実行してから使ってください。
  ```bash
  rm ~/.webclass-downloader/history.json
  ```
- ファイルが見つからなかった資料や、途中で失敗した資料は記録されないので、次回また確認します。

## ログイン状態（クッキー）について

- ログイン後の状態（クッキー）だけを `~/.webclass-downloader/login_state.json` に保存し、
  次回はそれを使って、ログインを省略できる場合があります（時間が経つと切れるので、そのときはまたログインします）。
- パスワードはどこにも保存しません。
- このファイルがあれば WebClass にログインした状態になれるので、人に渡さないでください。
  消したいときは次のコマンドで消せます（次回はまたログインが必要になります）。
  ```bash
  rm ~/.webclass-downloader/login_state.json
  ```

## 困ったとき

**「ログイン状態が切れたか、ログアウト画面に移動しました」と出た**
もう一度 `./run.sh` を実行してログインし直してください。途中までの分は記録されているので、続きから進みます。

**「この資料の中にファイルが見つかりませんでした」と出た**
資料の中に PDF が無い（文章だけの資料など）か、ツールが画面の形を読み取れなかった可能性があります。
調査用に、その画面の HTML が `~/.webclass-downloader/debug/` に保存されます。
（この HTML には氏名などの個人情報が含まれることがあるので、人に見せる前に中身を確認してください）

**節（目次）が複数ある資料で、一部しか保存されない**
`--debug` を付けて実行すると、各ページの画面が `~/.webclass-downloader/debug/` に保存されるので、原因を調べられます。

**「ブラウザを起動できませんでした」と出た**
`bash setup.sh` をもう一度実行してください。

**途中でやめたい**
ターミナルで `Control + C` を押します。それまでにダウンロードした分は記録されています。
