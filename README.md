# Yoshimi

TOEFL iBT（2026年新形式）Speaking / Writing の練習ページ「S/W 特訓ノート」の GitHub Pages 版です。

公開URL: https://yoshimi-claude.github.io/Yoshimi/

- `index.html` … ページ本体（claude.ai 版のアーティファクトと同じファイル）
- `audio/` … Listen & Repeat と Interview の音声（ニューラル音声合成）

GitHub 版では、Speaking をページ内のマイクで録音し、ブラウザの音声認識（Chrome / Edge 推奨）で自動採点できます。
Interview の AI 採点は claude.ai 版で行います（「claude.ai版で採点するためにコピー」→ claude.ai 版に貼り付け）。
記録はこの端末のブラウザ（localStorage）に保存されます。
「記録」タブの「claude.ai版へ記録を移す」で記録を書き出し（コピーまたは .json ファイル）、claude.ai 版の「記録」タブの「GitHub版の記録を取り込む」に貼り付けると、claude.ai 版の記録にまとめられます（同じ記録を何度取り込んでも二重にはなりません）。
